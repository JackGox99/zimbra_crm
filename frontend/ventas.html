Ventas

¿Cómo se gestionan las ventas?
  • 📋 Propuestas pendientes — ofertas enviadas a los prospectos esperando respuesta. Acción: click sobre una tarjeta para cerrar la venta. Las propuestas se crean desde la página de Prospectos con el botón + Propuesta.
  • 💰 Ventas cerradas — registros de venta con monto, método de pago y estado (Pagada / Pendiente / Anulada). Acción: botón Anular para revertir una venta.
¿Cómo se cierra una venta? Click sobre una propuesta Pendiente → confirmar método de pago → el sistema ejecuta una sola transacción que acepta la propuesta, crea el cliente, marca al prospecto como Convertido y registra la venta. Si algún paso falla, se revierte todo (ROLLBACK) y nada cambia.

Anular venta

Vas a anular la venta — por —.

El backend ejecuta una transacción: BEGIN → verificar estado → UPDATE estado='Anulada' → COMMIT. Si la venta ya estaba anulada, se hace ROLLBACK por regla de negocio y nada cambia.

Cerrar venta

Vas a cerrar la propuesta — de — por —.

El backend ejecutará la transacción: BEGIN → aceptar propuesta → SAVEPOINT crear cliente → convertir prospecto → registrar venta → COMMIT.
